# 偷花喵

一隻虎斑貓在晚上偷鄰居的花，白天由花店老闆美玲把花賣掉。用賺來的錢升級花喵、繳房租，一個月一個月撐下去。

## 怎麼玩

直接用瀏覽器打開 `index.html`（或打開本專案的 GitHub Pages 網址）就能玩，不用安裝。

## 玩法一覽

- **晚上偷花**：躲視線、爬屋頂、過屋頂走廊、鑽貓道、偷聽窗邊的秘密、跑酷連跳；被發現就賣萌（十幾種小遊戲）。
- **白天賣花**：包花束、接訂單和大型委託、熟客變 VIP、櫥窗佈置、貓咪店長區。
- **升級**：每學一招，花喵身上就多一樣配件；花店、頂樓花園、夜市花攤也會一級一級變樣。
- **服裝扭蛋**：帽子、眼鏡、披風，穿齊一套有套裝效果。
- **新區域**：下水道、公園、隔壁巷、清晨市場，各有新的花、新的對手和朋友。
- **配種新品種**：在頂樓配出藍玫瑰、月光蘭、銀河玫瑰……沒配對也會留下線索；每月有社區花展。
- **競爭對手**：隔壁巷的黑貓「煤炭」會來搶花（對決贏了牠就加入花喵幫）；第四個月對面開了連鎖花店，要比市佔率。
- **四季**：每季的花、晚上的規則、季節任務和限定衣服都不一樣。
- **花喵幫遠征**：派貓去河堤、夜市後巷、大學校園、花市、山上苗圃、花博公園，帶回花、插枝、紀念品和遠征日記。
- **口碑等級**：客人每天留評論，口碑越高賣得越貴、會有雜誌和電視台來採訪；偷太兇會傳出謠言。
- **每晚評價、成就、稀有的夜晚、圖鑑**。

## 檔案

- `index.html`：可以直接玩的完整遊戲（單一檔案）
- `src/`：原始碼
- `build.py`：把 `src/` 組合成遊戲檔，執行 `python3 build.py` 後輸出在 `dist/`
